# 📊 Customer Shopping Behavior Analysis
Data Analytics project showcasing customer behavior analysis using python, sql and power Bi.


## 📌 Overview

This project analyzes customer shopping behavior using **Python, SQL, and Power BI** to uncover purchasing trends and generate actionable business insights. The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, interactive dashboard creation, and report preparation. The project demonstrates an end-to-end data analytics pipeline suitable for portfolio and resume projects.

---

## 📂 Dataset

The dataset contains customer shopping information, including:

* Customer demographics
* Product category
* Purchase amount
* Payment method
* Discount usage
* Customer review ratings
* Frequency of purchases
* Shipping type
* Seasonal buying patterns

## 🔄 Project Workflow

### 1. Data Loading

* Imported dataset into Python.
* Inspected rows, columns, and data types.

### 2. Exploratory Data Analysis (EDA)

* Checked missing values and duplicates.
* Analyzed numerical and categorical variables.
* Visualized customer purchasing behavior.
* Identified trends and patterns.

### 3. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data types.
* Prepared clean dataset for analysis.

### 4. SQL Analysis

Executed SQL queries to answer business questions such as:

* Revenue by gender
* Average purchase amount
* Most popular product categories
* Seasonal sales analysis
* Discount usage
* Customer spending behavior

### 5. Power BI Dashboard

Created an interactive dashboard featuring:

* KPI Cards
* Sales by Category
* Revenue by Gender
* Purchase Trends
* Discount Analysis
* Customer Demographics
* Interactive Filters (Slicers)

### 6. Reporting & Presentation

* Summarized key business insights.
* Prepared a professional report.
* Created a presentation using **Gamma AI**.

## ▶️ How to Run

### Python

1. Open the Jupyter Notebook.
2. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Run all notebook cells.

### SQL

1. Import the dataset into PostgreSQL, MySQL, or SQL Server.
2. Execute the SQL script to perform analysis.

### Power BI

1. Open the `.pbix` file.
2. Refresh the data (if required).
3. Explore the interactive dashboard.
